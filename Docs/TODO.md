Ты помогаешь мне построить MVP веб-приложения для изучения иностранных слов (аналог Quizlet).

КОНТЕКСТ ПРОЕКТА:
- Backend: Go (net/http или chi/gin на выбор, предпочтительно gin для скорости разработки)
- Frontend: HTML + CSS + JS (vanilla, без фреймворков)
- БД: SQLite (через modernc.org/sqlite или mattn/go-sqlite3)
- Упаковка: Docker + docker-compose
- Авторизация: OAuth2 через Yandex, VK и GitHub (golang.org/x/oauth2)

ФУНКЦИОНАЛ:
1. Пользователь логинится через Google или GitHub
2. Пользователь создаёт/удаляет карточки (слово — перевод, на родном/иностранном языке)
3. Перевод слова подтягивается через бесплатный API переводчика (LibreTranslate, self-hosted или публичный инстанс)
4. Карточки группируются в стопки (decks)
5. Режим "квиз": выбор стопки → показ карточек в случайном порядке → ввод/выбор перевода → подсчёт результата
6. Офлайн-режим: Service Worker кэширует последнюю загруженную стопку в IndexedDB; при отсутствии сети приложение работает с кэшем, при восстановлении сети — синхронизирует изменения
7. UI: Apple-like минималистичный стиль, светлая/тёмная тема, выбор акцентного цвета (CSS-переменные)
8. Монетизация: подписочная модель
   - Бесплатно: до 100 карточек и 1 стопка на аккаунт
   - Платно: 99₽/мес — безлимит карточек и стопок
   - У пользователя в БД поля is_premium (bool) и premium_until (datetime)
   - Проверка лимитов — на бэкенде (middleware), не только на фронте

ЗАДАЧА НА ЭТОТ ШАГ:
Начни с настройки проекта:
1. Структура репозитория (backend/, frontend/, docker-compose.yml)
2. Go-модуль с базовой структурой (main.go, роутер, подключение SQLite, миграции через golang-migrate или простой SQL-скрипт)
3. Заглушка OAuth для Google и GitHub (роуты /auth/google, /auth/github, /auth/callback)
4. Dockerfile для backend + docker-compose с volume для SQLite-файла
